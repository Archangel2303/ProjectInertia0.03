# Asset Attribution

This file tracks third-party assets used in this project and the attribution required by their licenses.

## How to use this file

- Add one section per external asset pack, model, texture, sound, font, or shader.
- Keep source URLs and license names exact.
- If a license requires attribution text, include it verbatim.
- If you modified an asset, describe the modification.

---

## Attribution Entry Template

### Asset: <asset or pack name>
- Source: <URL>
- Author: <name or handle>
- License: <e.g., CC BY 4.0>
- License URL: <URL>
- Copyright Notice: <if provided>
- Required Attribution Text:
  > <paste exact attribution text required by the creator/license>
- Modifications Made: <none / describe edits>
- Files Used In Project:
  - <path/to/file1>
  - <path/to/file2>
